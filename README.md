# 青清诗集

一座古诗词名句画册网站：168 句名句，一句一画，分作九卷。

- **九卷横卷**：山水 · 月夜 · 风雪 · 花木 · 酒茶 · 相思 · 乡关 · 豪侠 · 人生，按住卷带拖拽展卷
- **暗室沉浸**：一盏灯、一幅画、一句诗，逐句流连
- **翻面看画**：有画的句子，翻过卡片来便是画

纯静态站点，零依赖、零构建，打开即读。
